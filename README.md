# Connectly 💬

A modern real-time messaging platform built with the MERN stack featuring secure authentication, file sharing, online presence, and WebSocket-based communication.

## Features

- JWT Authentication
- Real-time Chat
- Image Sharing
- User Presence
- Typing Indicators
- MongoDB
- Socket.io

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- Socket.IO
- TailwindCSS

npm install
npm run dev
